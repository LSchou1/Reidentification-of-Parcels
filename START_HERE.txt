BACHELOR DETECTION - START HERE

1. OPEN TERMINAL

cd "/Users/lasseschou/Desktop/RobTek/Bachelor/bachelor-detection"

2. CHOOSE DATA AND CLASSES IN workflow.yaml

batches: [next_batch, real_photos]
classes: [barcode, label, parcel]
split_mode: exploratory

Remove a batch or class to skip it. Each batch gets its own model and results.
Different pictures of the same parcels are allowed in different sets.
Exact duplicate pictures stay together. No parcel IDs are needed.

3. TRY PRETRAINED DETECTION (NO TRAINING)

.venv/bin/python workflow.py inspect --confidence 0.05

4. TRAIN AND COMPARE

The current pictures are already annotated.
Run these ONE AT A TIME and let each finish:

.venv/bin/python workflow.py split
.venv/bin/python workflow.py baseline
.venv/bin/python workflow.py train --dry-run
.venv/bin/python workflow.py train
.venv/bin/python workflow.py validate
.venv/bin/python workflow.py test

split          = fixed 70/15/15 training/validation/test split
baseline       = pretrained model analysis before training
train --dry-run = check the setup without training
train          = train on your pictures; CPU can take a long time
validate       = analyse the trained model and choose confidence
test          = evaluate both models and make the comparison

Reuse the same split. Change run_name in workflow.yaml for another experiment.

5. OPEN RESULTS

open data/output/next_batch/index.html
open data/output/real_photos/index.html

Follow the HTML links for pictures, precision, recall, F1, IoU,
confusion matrix and confidence curves.

NEW PICTURES LATER

Put them in data/raw/new_batch/ and set batches: [new_batch].
Run .venv/bin/python workflow.py prepare, then ask me to annotate them.
Once reviewed, follow steps 3-5.

FOLDERS

data/raw/       = clean original pictures
data/annotated/ = reference pictures with boxes and annotations.json
data/output/    = detection results, analyses and trained models
tmp/            = temporary files; safe to delete when no command is running

Training always uses clean originals and the JSON coordinates.
